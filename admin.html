Import schedule or agent results

Upload the original schedule, an updated address list, or the results CSV received from a field agent. Files merge by Assignment Number; existing submitted reports won't be overwritten by a blank schedule.

Semicolon CSV exported from Excel works offline. XLSX supported in recent Chrome/Edge.

Export data

Always retain a full backup. To update agents' available addresses, export the Agent Schedule CSV and send it to them.

Update the online Schouw app

To make added/removed addresses or agent names available to everyone, open Agent names and select Download updated website ZIP. Redeploy it in Netlify.

Manage agent names

Import a team list from CSV or Excel, or add/remove names individually. After changes, select Download updated website ZIP and redeploy it to Netlify. The Schouw dropdown will use your published names.

Accepted columns: Agent, Agent Name, Name, Full Name, or First Name + Last Name. Plain lists with one name per row also work.

Publish changes to your Schouw website

Your saved changes remain on this administrator's browser until you publish. This button packages the updated agent names + schedule into a ready-to-upload website ZIP. Agent reports remain private to each device and are NOT embedded in the public website.

After downloading, upload the extracted folder through Netlify → Deploys.
